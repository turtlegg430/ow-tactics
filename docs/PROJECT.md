# PROJECT — 비전, 목표, 로드맵

최종 수정: 2026-09-30

## 왜 만드는가
오버워치는 에임만 좋으면 되는 평범한 FPS가 아니라, 체스나 바둑처럼 고도의 수싸움이 필요한 게임이다. 많은 유저가 더 잘하고 싶어 하지만 운영(턴, 스킬 교환, 자리 선점)에 대한 이해도를 높이기 어려워한다. 이런 판단 능력은 영상을 보는 것만으로는 잘 늘지 않고, 직접 판단하고 틀려봐야 는다.

## 목표
1. **개발을 배우며 만든다** — 필수 용어, GitHub 사용법, 웹 배포까지 이 프로젝트를 통해 익힌다.
2. **운영 학습 게임을 만든다** — 저티어부터 고티어까지 운영 판단을 게임처럼 학습할 수 있는 프로그램.

## 핵심 경험
상황 제시 → 플레이어가 판단을 고름 → 그 선택의 결말을 눈으로 확인 → 되감아서 다른 선택과 비교 → 원리 해설

## 형태
- 2.5D(비스듬히 내려다본) 탑뷰 전술 보드 + 해당 순간의 1인칭 게임 캡처를 짝지어 보여준다.
- 웹 브라우저에서 설치 없이 실행하고, 링크로 공유한다. 배포 주소: https://turtlegg430.github.io/ow-tactics/ (D-050)
- 문제 내용은 코드와 분리된 데이터로 관리한다 → 나중에는 코딩 없이 문제 추가.

## 차별점 (유튜브 피드백 영상 대비)
- 남의 판단을 구경하는 게 아니라 직접 고른다.
- 틀린 선택의 결말까지 보여주고, 같은 순간을 되감아 비교한다.
- 문제마다 필요한 정보만 보여줘 변수를 통제한다.
- 티어별 커리큘럼으로 묶을 수 있다 (구성은 추후 확정).
