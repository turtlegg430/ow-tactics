## 표현 원칙
- **2.5D 탑뷰**: 비스듬히 내려다보는 시점. 3D 엔진 없이 높이감을 준다.
- **인게임 화면 먼저, 탑뷰는 그다음**: 문제는 1인칭 인게임 캡처로 시작하고, 이어서 같은 순간의 탑뷰 보드를 보여준다. 보드만 먼저 보면 "여기가 어디지?"가 되기 때문. 탑뷰에서 설명한 요소(위험 구역, 시야선 등)는 1인칭 화면에서도 어디인지 함께 표시한다.
- **맵은 정확한 도면**: 실제 구조와 비율을 살리고, 유저들이 쓰는 콜아웃 이름과 랜드마크를 표시한다. 과한 단순화 금지. 지형 높이는 워크숍 스캔으로 잰 실측값을 쓴다 (D-059).
- **회전**: 보드는 90° 단위로 돌려볼 수 있다. 돌아가는 과정을 부드럽게 보여줘 방향 감각을 유지한다. 작은 방향 표시(맵 윤곽 + 기준 구역)를 함께 둔다.

## 가려진 곳
- 영웅·시체·화물이 앞 구조물에 가려진 자리에 있으면 **그 아이콘을 반투명하게 하고 점선 고리**를 두른다. 지형은 그대로 둔다. (D-023)
- 공중에 뜬 영웅은 그림자가 아니라 실제 떠 있는 높이를 기준으로 가려졌는지 판단한다.
- 반투명 영웅과 시체는 모양으로 구분된다 (시체는 바닥에 깔린 타원).
- 탐지·노출로 드러난 영웅은 가려져 있어도 반투명으로 흐리지 않는다 (D-047). 전체 노출(위도우메이커 적외선 투시 등)은 붉은 실루엣, 구역 탐지(한조 음파 화살)는 탐지한 팀 색 윤곽.
- 실내·처마 밑은 위층 면을 덮어 그리고 안의 영웅만 반투명으로 보여 준다 (D-065). 지하도 같은 방식이 기본안이며, 지하가 있는 맵에서 확인한다 (보류).

## 쿨타임 표시 (HUD 스킬 칸, 토큰 옆 딱지 공통)
- 스킬을 쓰면 칸이 **주황색으로 가득 차고**, 쿨타임이 흐르면서 **물 빠지듯 위에서부터 줄어든다.** 남은 초를 숫자로 함께 표시한다.
- 준비되면 주황이 사라지고 아이콘이 밝아진다.
- 게이지 색은 **반투명하고 채도를 낮춘 주황**으로, 읽히되 눈에 너무 띄지 않게 한다.
- 토큰 옆 **쿨타임 딱지는 오른쪽, 상태 딱지는 왼쪽**에 붙인다 (D-041). 상태 딱지는 같은 물 빠지는 게이지를 쓰되 색이 효과 종류 색이다 (D-042).

## HUD (화면 UI)
- **초기 오버워치 UI 스타일을 단순화**해서 따른다. 칸은 기울어진 평행사변형.
- 구성 요소: 상단 양 팀 초상화 줄(생존 여부, 궁 게이지, 궁 준비 표시) / 킬로그 / 주인공 영웅 체력바(칸 단위, 체력 4색) / 궁 게이지 % / 스킬 칸(단축키, 쿨타임) / 탄약
- **킬로그 (D-035, D-048)**: 킬로그 칸 모양은 그대로 두고, 처치한 영웅과 처치당한 영웅 사이의 **두꺼운 화살표(왼쪽 → 오른쪽) 색만** 바꾼다. 일반 킬은 흰 화살표, 치명타 킬은 붉은 화살표. 무기 아이콘·해골·테두리·붉은 배경은 쓰지 않는다. 결말 재생 중 올라오는 킬로그도 같은 규칙.
- **HUD 체력바**: 칸 단위, 체력 4색 (D-030). 치유 불가·증폭이면 체력바 테두리 색이 바뀐다 (D-043).
- 블리자드 그림(영웅 초상화, 스킬 아이콘 등): 시안에서는 대체 그림을 쓴다. 공개 배포 전 사용 가능 범위를 확인해서 결정 (DECISIONS 보류 항목).

### 분류 규칙
- **상태 딱지는 항상 붙인다 (D-027).** 기절, 넘어뜨림, 이동기 봉쇄, 수면, 해킹, 저지 불가, 치유 불가, 치유 증폭, 속도 증가·감소, 화상·출혈·독처럼 영웅에게 걸리는 효과는 다른 분류와 함께 쓰여도 딱지를 붙인다.
- **딱지를 붙이지 않는 것 (D-038).** 추가 생명력·보호막은 체력 색(D-030)으로만 보여준다. 구역 안에 있어서 받는 버프(루시우 음악, 메이 스케이트장 등)는 구역 색으로만 보여준다.
- **저지 불가는 딱지, 진짜 형태 변화는 모드 (D-038).** 마우가 돌파의 저지 불가는 딱지. 오리사 방어 강화처럼 움직임 자체가 바뀌는 건 모드로 둔다.
- **저격 모드는 모드로 구분한다 (D-028).** 토큰 원 안에 연한 스코프(또는 토큰 옆 스코프 아이콘)를 넣어 다른 모드와 구분한다.
- **약하게 밀리는 것도 강제 이동이다 (D-029).** 밀리는 거리가 짧아도 잠깐이라도 보이게 그린다.
- **강제 이동의 화면 문구는 종류별로 (D-036).** 분류는 '강제 이동' 하나지만, 화면에는 밀침 / 살짝 밀침 / 끌어당김 / 띄움 / 띄운 뒤 내리꽂음 / 붙잡아 끌고 감처럼 상황에 맞는 글자를 쓴다. 줄마다 어떤 문구인지는 매핑표 R열에 있다.
- **방벽 모양은 5가지다 (D-031).** 호, 평면, 돔, 감싸기(자리야처럼 영웅을 감싸는 구), 통과 면(바티스트 증폭 매트릭스처럼 막지 않는 면).
- **이동 경로는 영웅이 아닌 것에도 쓴다 (D-032).** 방벽, 구역, 조종하는 투사체처럼 움직이는 물체의 길도 이동 경로로 그린다.
- **임시 물체 (D-037 → D-046).** 리퍼 영혼 구슬과 라이프위버 씨앗만 이 분류로 그린다. 부술 수 있는 구조물과 달리 체력이 없고, 보는 사람이 헷갈리지 않게 물체 이름표를 늘 붙인다. 메이 빙하 추진력(2단 점프 얼음)은 이동 경로로만, 바티스트 자동화 치유(견착 포탑)는 표시 안 함.
- **강제 이동은 궤적을 그리지 않는다 (D-044).** 밀치는 범위(부채꼴 등)와 밀려나는 움직임, 화면 문구만. 화살표가 있으면 오히려 복잡하고 헷갈린다.
- **견인·운반은 연결선으로 묶는다 (D-045).** 경로 화살표 없이 연결선(스킬 색)과 함께 움직이는 모습만. 끌려가는 동안 무적이면(구원의 손길) 대상을 스킬 색 막으로 감싼다.
- **탐지와 노출은 따로 그린다 (D-047).** 한조 음파 화살 같은 구역 탐지는 파동과 탐지한 팀 색 윤곽. 위도우메이커 적외선 투시·수색가처럼 적을 드러내는 노출은 붉은 실루엣(벽 너머에서도).

### 딱지 띄우는 기준 (확정 — D-039)
딱지를 데이터에는 전부 적되, 화면에는 우선순위대로 골라 띄워서 정신없지 않게 한다.

| 순위 | 효과 | 화면 |
|---|---|---|
| 1 | 제어·위험: 기절, 넘어뜨림, 수면, 해킹, 이동기 봉쇄, 저지 불가, 치유 불가 | 걸리면 항상 띄움 |
| 2 | 싸움 결과를 바꾸는 강화·약화: 공격력 증폭, 받는 피해 증가, 치유 증폭, 화상·출혈·독 | 문제에 관련 있으면 띄움 |
| 3 | 자잘한 버프: 이동·공격·재장전 속도 증가, 스스로 회복 | 평소엔 숨기고, 해설에서 짚을 때만 띄움 |

- 토큰 하나에 딱지는 최대 2개. 넘치면 "+2"처럼 개수만 보여주고, 해설에서 펼친다.
- 같은 순위끼리는 남은 시간이 긴 것부터. 딱지 색은 효과 종류 (D-042).
- 표에 없는 효과: 공용 치유 감소는 늘 걸려 있어 3순위(평소 숨김), 속도 감소는 약화라 2순위로 둔다.

### 공통
- **궁극기는 따로 분류하지 않는다.** 위 분류의 조합에 금색 강조를 더한다. (예: 대지분쇄 = 폭발·범위 + 기절 딱지, 나노강화제 = 연결선 + 상태 딱지)
- 쓰임은 두 가지: 결말 재생 중 일어나는 순간을 짧게 보여주기, 해설·시선 순서에서 지금 짚는 것만 띄우기. 모든 범위를 늘 띄우지 않는다.
- 공통 문법: 공격·방벽·설치물·흡수 호·구역 테두리는 시전자 팀 색, 연결선·상태 딱지·구역 안쪽은 효과 색 (D-042) / 순간은 진하게 번쩍, 지속은 옅게. 사거리·각도·반경은 실제 수치를 쓰고 사용자가 검수한다.
- 한 장면에서 관련 없는 영웅은 흐리게 두고 지금 짚는 것만 또렷하게 한다 (시안의 '관련 없는 영웅 흐리게'와 같은 방식).
- 도형 위치는 문제 작성자가 정한다. 시야 계산이나 명중 판정 같은 시뮬레이션은 하지 않는다.
- 10/6 패치 이후 줄(로드호그·솜브라 리워크, 독트린)은 매핑표에서 '보류'. 패치 뒤 확인해서 채운다.
