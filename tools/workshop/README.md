# 워크숍 맵 스캐너 (v5)

오버워치 워크숍(사용자 지정 게임)에서 돌리는 맵 스캐너 코드다. 맵 위에 0.5m 간격 격자를 깔고, 점마다 광선을 위에서 아래로 쏴서 맞은 면의 높이와 기울기를 기록한다. 기록은 워크숍 인스펙터에서 CSV로 복사해 가져오고, `scripts/import-scan.ts`가 게임 지형 데이터로 바꾼다 (D-059, D-062, D-064).

| 파일 | 내용 |
|---|---|
| `map-scanner-v5-kingsrow-a-1.txt` | 왕의 길 A 조각 1 (X −76부터 71열) |
| `map-scanner-v5-kingsrow-a-2.txt` | 왕의 길 A 조각 2 (X −40.5부터 71열) |
| `map-scanner-v5-kingsrow-a-3.txt` | 왕의 길 A 조각 3 (X −5부터 67열) |

스캔 원본 CSV, StatBanana 그림과 맞춤값은 저장소에 넣지 않고 기획 작업 폴더 `스캔\`에 둔다.

## 사용법
1. 게임 텍스트 언어를 **English**로 둔다. 한국어 게임은 코드 키워드가 달라서(`actions` 대신 `action` 등) 붙여넣기가 안 된다.
2. 코드 파일 전체를 복사하면 워크숍 화면에 붙여넣기 버튼이 생긴다. 맵은 왕의 길, 수비 팀. 영웅은 아무나 상관없다.
3. 게임을 시작하고 **앉은 채 F**를 누른다. HUD의 Row가 176까지 올라가면 "Chunk n done"이 뜬다. 조각 하나에 약 3분 20초 걸린다.
4. ESC → 워크숍 인스펙터 → **4번째 버튼** (ALL VARIABLES … AS CSV TEXT)으로 복사한다. 변수 대상이 Global이든 플레이어든 둘 다 읽힌다.
5. 메모장에 붙여 넣고 첫 줄이 `00:00:00,Global,…`인지 확인한다. `variables`로 시작하면 복사가 실패한 것이다.
6. 로비로 나가 다음 조각 코드로 반복한다. **조각마다 새 게임**으로 해야 앞 조각 기록이 쌓이지 않는다.
7. CSV 세 개를 스캔 폴더에 두고 변환한다.

```
npm run import-scan -- "<스캔 폴더>"
```

- 스캔 범위는 코드에 숫자로 들어 있다(`X0`, `NX`, `Z0`, `NZ`). 게임 안에서 모서리를 찍지 않는다. 범위는 StatBanana 지도 위에서 정한다.
- 한 번에 복사할 수 있는 양에 한계가 있다. 1.3MB는 성공, 약 3MB는 조용히 실패(클립보드에 이전 내용이 남음), 더 크면 게임이 튕겼다. 그래서 맵을 조각으로 나누고, v5는 층 값을 숫자 하나로 줄여 조각당 약 0.7MB다.

## 스캔 방식
- 게임 좌표축에 맞춘 네모를 0.5m 간격으로 훑는다. 점마다 Y 90m에서 −40m로 광선을 쏜다. 맞으면 맞은 곳 0.3m 아래에서 다시 쏘고, 최대 6번(층 6개).
- 광선이 물체 안에서 출발하면 그 물체의 면은 맞지 않고 빠져나간다. 그래서 지붕 밑 실내 바닥은 잡히지만 천장 아래면은 잡히지 않는다.
- 왕의 길 A: X −76~28, Z −62~26, 209×177점, 3조각.

## CSV 형식
- 한 줄 = `시간, 대상 이름(Global 또는 플레이어 이름), 변수 128칸`. 같은 기록이 두 줄씩 들어가므로 중복은 버린다.
- 대상이 Global이면 첫 변수 칸(Row)에 기록이 남는다. 플레이어이면 18번 변수(Temp) 칸에 같은 줄이 남고, 머리 정보는 X0·Z0 등 변수 칸에서 읽는다.
- Row 기록은 `[값;값;…]` 모양이다.
  - 머리 줄 `[-1; X0; Z0; Step; NX; NZ; YTop; YBot; Layers; 조각 번호; 형식(2)]`
  - 데이터 줄 `[J; 점0의 층1~6; 점1의 층1~6; …]`. 점 i의 위치는 x = X0 + i × Step, z = Z0 + J × Step
  - 끝 줄 `[-2; 조각 번호]`
- 층 값 c: 0이면 맞은 것 없음. 아니면
  - **높이 y = (c ÷ 100의 몫 − 1000) ÷ 20** (m, 5cm 단위)
  - **법선 y = (c ÷ 100의 나머지) ÷ 99** (1 = 평평, 0 = 수직)
- **게임의 욕설 필터가 숫자 속 `1488`을 `****`로 가린다.** `1488`로 되돌리면 이웃 값과 맞는다 (왕의 길 A 본 스캔에서 29개).
- 좌표: Y가 위. **+Z를 바라보면 +X가 왼쪽이다.** 위에서 본 그림을 +Z가 위로 그리면 +X는 왼쪽에 와야 한다. X를 그대로 오른쪽으로 그리면 좌우가 뒤집힌다. 변환한 지형 데이터는 이 뒤집기를 마친 보드 좌표로 저장한다.
